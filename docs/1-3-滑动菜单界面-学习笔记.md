# 1-3 滑动菜单界面 — 学习笔记

## 学习目标

本节重点是学习 OLED 上的帧动画和菜单状态管理。菜单不是简单切图，而是通过位置变量逐帧移动图标。

对应代码：

- `APP/src/app_menu.c`
- `RES/src/ui_resources.c`
- `HARDWARE/src/OLED.c`

## 单片机知识点

### 1. OLED 坐标系统

OLED 坐标原点在左上角：

```text
x: 0 -> 127
y: 0 -> 63
```

图标通过 `OLED_ShowImage(x, y, width, height, image)` 绘制到指定位置。

### 2. 帧动画

帧动画的核心是“每次循环只移动一点”：

```c
x_pre -= Speed;
OLED_Update();
```

多次刷新后，人眼看到的就是连续滑动。

### 3. 菜单状态变量

菜单动画由这些变量控制：

```c
static uint8_t pre_selection;
static uint8_t target_selection;
static uint8_t x_pre = 48;
static uint8_t Speed = 4;
static uint8_t move_flag;
static uint8_t menu_flag = 1;
```

含义：

- `menu_flag`：当前选中的应用编号。
- `pre_selection`：动画起点。
- `target_selection`：动画目标。
- `x_pre`：当前中心图标的 x 坐标。
- `Speed`：每帧移动的像素数。
- `move_flag`：是否需要重新设置动画起点和目标。

## 代码解析

### `App_Menu()`

这是菜单入口。按键逻辑：

- `Key1`：左移。
- `Key2`：右移。
- `Key3`：确认当前应用。

确认后根据 `menu_flag_temp` 调用对应应用：

```c
App_Stopwatch_Run();
App_Flashlight_Run();
App_MPU6050_Run();
App_Dino_Run();
App_Emoji_Run();
App_Gradienter_Run();
```

### `Menu_Animation()`

该函数负责每一帧的绘制：

1. 清屏。
2. 画选中框 `Frame`。
3. 根据滑动方向更新 `x_pre`。
4. 绘制中心图标和左右相邻图标。
5. `OLED_Update()` 刷屏。

### `MenuToFunction()`

这是进入应用前的过渡动画。它把当前图标向下移动几帧，让菜单切到应用时不那么突兀。

## 注意点

- 菜单动画是阻塞式绘制，不是后台动画。
- `menu_flag_temp` 只在确认键后生效，避免滑动过程中误进入应用。
- `Menu_Graph` 是二维图片数组，放在 `RES/src/ui_resources.c`。
- 菜单最多显示 7 个应用，新增应用时要同步资源、菜单编号和入口调用。
