## 二、帧动画原理

### 2.1 为什么叫"帧动画"

每按一次方向键，图标不是瞬间跳变，而是**分多帧平滑滑动**：

```
帧1: x_pre=48 ──────── 帧2: x_pre=44 ──────── 帧3: x_pre=40 ── ... ── 帧12: x_pre=0
     [图标A在中间]           [向右移了4px]            [又移了4px]             [切换完成]
```

**每帧移动 `Speed = 4` 像素**，直到到达目标位置（`x_pre == 0` 或 `x_pre == 96`），动画结束。

### 2.2 坐标系统

```
屏幕宽度 128px

  -96     -48      0      48      96     144     192    ← 图标X坐标
   │       │       │       │       │       │       │
   │  [前2个] [前1个] [当前选中] [后1个] [后2个]  │
   │           └─────────┬─────────┘               │
   │                     │                         │
   └────────────────── 屏幕可见范围 ───────────────┘
```

同一帧画 5 个图标，左右各两个在屏幕外，只有中间的 1~3 个在屏幕内可见。

### 2.3 动画状态机

```
静态（move_flag=0）
  │
  ├── 按左键/右键 → move_flag=1, 设定目标
  │
  ▼
移动中（move_flag=1）
  │
  ├── 每帧 x_pre ±= Speed
  │
  ├── x_pre 到达 0 或 96 → move_flag=0, 切换完成
  │
  ▼
静态（move_flag=0）← 循环
```

```c
void Menu_Animation(void)
{
    OLED_Clear();
    OLED_ShowImage(42, 10, 44, 44, Frame);    // 画选中框

    if (pre_selection < target_selection)      // 向左移动
    {
        x_pre -= Speed;
        if (x_pre == 0)                        // 到达目标
        {
            pre_selection++;
            move_flag = 0;                     // 停止移动
            x_pre = 48;                        // 重置坐标
        }
    }

    if (pre_selection > target_selection)      // 向右移动
    {
        x_pre += Speed;
        if (x_pre == 96)
        {
            pre_selection--;
            move_flag = 0;
            x_pre = 48;
        }
    }

    // 画5个图标
    OLED_ShowImage(x_pre - 48, ...);   // 前2个
    OLED_ShowImage(x_pre - 96, ...);   // 前1个
    OLED_ShowImage(x_pre, ...);        // 当前（在Frame框中）
    OLED_ShowImage(x_pre + 48, ...);   // 后1个
    OLED_ShowImage(x_pre + 96, ...);   // 后2个

    OLED_Update();
}
```

### 2.4 关键参数

| 变量 | 类型 | 含义 |
|:---|:---|:---|
| `pre_selection` | `uint8_t` | 当前选中的图标下标（0~6） |
| `target_selection` | `uint8_t` | 目标图标下标 |
| `x_pre` | `uint8_t` | 当前图标的屏幕 X 坐标（48=中央） |
| `Speed` | `uint8_t` | 每帧移动像素（4px） |
| `move_flag` | `uint8_t` | 移动标志（1=动画中，0=静止） |
| `DirectFlag` | `uint8_t` | 移动方向（1=向左，2=向右） |

### 2.5 首尾循环的特殊处理

```c
if (menu_flag == 1)  // 选中第1项（返回按钮）
{
    if (DirectFlag == 1)
        Set_Selection(move_flag, 1, 0);   // 从位置1移到位置0
    else if (DirectFlag == 2)
        Set_Selection(move_flag, 0, 0);   // 从位置0移到位置0（不动）
}
else  // 普通项
{
    if (DirectFlag == 1)
        Set_Selection(move_flag, menu_flag, menu_flag - 1);
    else if (DirectFlag == 2)
        Set_Selection(move_flag, menu_flag - 2, menu_flag - 1);
}
```

`pre_selection` 可以等于 0，对应 `Menu_Graph[0]` 之前的"虚拟位置"。`Menu_Graph` 下标 0~6 对应 7 个图标，边界检查用 `>= 1` 和 `>= 2` 防止数组越界。

## 三、图像数据数组

### 3.1 二维数组存储多图标

```c
// OLED_Data.h
extern const uint8_t Menu_Graph[][128];

// OLED_Data.c
const uint8_t Menu_Graph[][128] = {
    { /* 0: 退回图标 32×32 */ },
    { /* 1: 秒表图标 32×32 */ },
    { /* 2: 手电筒图标 32×32 */ },
    { /* 3: 小恐龙图标 32×32 */ },
    { /* 4: 表情包图标 32×32 */ },
    { /* 5: 水平仪图标 32×32 */ },
    { /* 6: 关机图标 32×32 */ },
};
```

**一个 32×32 图标 = 32 ÷ 8 × 32 = 4 页 × 32 列 = 128 字节。**

### 3.2 为什么用 `[][128]` 而非 `[7][128]`

第一维留空让编译器自动推断，方便以后增减图标。编译器看到初始化列表有 7 个元素，自动推断出 `[7][128]`。

### 3.3 访问方式

```c
Menu_Graph[pre_selection]      // 第 pre_selection 个图标（指向 128 字节的指针）
Menu_Graph[pre_selection + 1]  // 下一个图标
```

`OLED_ShowImage(x, y, 32, 32, Menu_Graph[i])` — 把数组名当下标用，得到的是 `const uint8_t*` 指针，指向 128 字节的图标数据。

## 四、Frame 选中框

```c
const uint8_t Frame[] = { ... };  // 44×44 像素

// 使用
OLED_ShowImage(42, 10, 44, 44, Frame);
```

Frame 画在 (42, 10)，宽度 44 覆盖了中央的 32×32 图标区域，形成一个"选中框"的视觉效果。图标在框内，框不动，图标滑动——这就是苹果 Cover Flow 式的菜单效果。

Frame 大小：44×44 像素 ≈ 6 页 × 44 列 = 264 字节。

## 五、1-3 新知识点

| 知识点 | 在哪用到的 |
|:---|:---|
| **帧动画** | `Menu_Animation()` 中 `x_pre ±= Speed`，每帧移动 4px |
| **二维图像数组** | `Menu_Graph[7][128]`，7 个 32×32 图标 |
| **数组下标访问图像** | `Menu_Graph[pre_selection]` |
| **动画状态机** | `move_flag` 控制移动/静止 |
| **方向标志** | `DirectFlag` 记录移动方向 |
| **边界循环** | `menu_flag <= 0 → 7`，`menu_flag >= 8 → 1` |
| **数组越界防护** | `if (pre_selection >= 1)` 防止访问 `Menu_Graph[-1]` |
