## 二、多级页面跳转

### 2.1 页面层级

```
main() while(1)
  └→ First_Page_Clock()        // 阻塞，返回 clkflag
       └→ SettingPage()         // 阻塞，返回 0 或进入 SetTime()
            └→ SetTime()        // 阻塞，返回 0 或进入 SetYear/Month/...
                 └→ SetYear()   // 阻塞，返回 0
```

**每一级都是独立的 `while(1)` 死循环，return 就是"返回上一级"。**

### 2.2 为什么用 return 0？

```c
int SettingPage(void)
{
    while (1) {
        ...
        if (setflag_temp == 1) { return 0; }  // 返回上一级
    }
}
```

单片机没有操作系统，函数栈就是你天然的"返回路径"。`return` 后 CPU 回到调用者的 `while(1)` 里继续跑——这就是裸机的页面导航。

### 2.3 临时变量解状态问题

```c
uint8_t setflag_temp = 0;       // 先暂存
if (KeyNum == 3) {
    setflag_temp = setflag;     // 确认时记录当前选项
}
if (setflag_temp == 1) return;  // 然后处理跳转
if (setflag_temp == 2) SetTime();
switch (setflag) { ... }        // 继续正常导航渲染
```

**问题：** 如果确认后直接 `return` 或调用子页面，那一帧的屏幕渲染（switch-case）就不会执行了——屏幕会残留上次的内容。  
**解决：** 用 `setflag_temp` 暂存"要跳转的目标"，先让 switch-case 渲染完当前帧，下一轮循环才跳转。

## 三、跨文件变量共享（extern）

### 3.1 问题

`Key_Num` 在 `Key.c` 中定义，`SetTime.c` 也要用。

### 3.2 解决方案

```c
// Key.c（定义）
uint8_t Key_Num;

// menu.c（定义，被 SetTime.c 引用）
uint8_t KeyNum;

// SetTime.c（声明，不定义）
extern uint8_t KeyNum;
```

| 关键字 | 含义 | 位置 |
|:---|:---|:---|
| `uint8_t KeyNum;` | **定义**：分配内存 | `menu.c`（只能一处） |
| `extern uint8_t KeyNum;` | **声明**：告诉编译器"这个变量在别的文件里" | `SetTime.c` |

**规则：** 全局变量只能在一个 `.c` 文件中定义，其他文件用 `extern` 引用。否则链接阶段报重复定义错。

## 四、数值边界检查

### 4.1 加减后的边界处理

```c
// 加 1 后检查上限
Change_RTC_Time(1, 1);                      // 月 +1
if (MyRTC_Time[1] >= 13)                    // 超出 12 月
{
    MyRTC_Time[1] = 1;                      // 回到 1 月
    MyRTC_SetTime();                         // 写回 RTC
}

// 减 1 前检查下限（注意：MyRTC_Time 是 uint16_t，不能 < 0）
if (MyRTC_Time[3] == 0)                     // 已经是 0 时
{
    MyRTC_Time[3] = 23;                     // 回到 23 时
    MyRTC_SetTime();
}
else
{
    Change_RTC_Time(3, 0);                  // 正常 -1
}
```

**关键细节：** `MyRTC_Time[]` 是 `uint16_t`（无符号），所以 **不能写 `if (MyRTC_Time[i] < 0)`**——这个条件永远不成立。必须先判断 `== 0` 再处理。

### 4.2 各字段范围

| 字段 | 范围 | 循环方式 |
|:---|:---|:---|
| 年 | 无限制 | 任意加/减 |
| 月 | 1 ~ 12 | 12→1, 1→12 |
| 日 | 1 ~ 31 | 31→1, 1→31 |
| 时 | 0 ~ 23 | 23→0, 0→23 |
| 分 | 0 ~ 59 | 59→0, 0→59 |
| 秒 | 0 ~ 59 | 59→0, 0→59 |

## 五、图像数据

### 5.1 什么叫"取模"

汉字或图标本质上是一张 16×16 的**二值位图**（每个像素要么亮要么灭）。取模就是把这张位图转成一串十六进制数。

```
Return 图标（16×16 箭头）：

视觉上：              →      数据上（前两行）：
  ░░░░░░░░░░░░░░░░          0x00,0x00,0x80,0xC0,0xE0,0xF0,...
  ░░░░█████░░░░░░░
  ░░░███████░░░░░░          0x00,0x01,0x03,0x07,0x0F,0x1F,...
  ░░█████████░░░░░░
  ...
```

### 5.2 使用方式

```c
// OLED_Data.c 中定义
const uint8_t Return[] = {
    0x00,0x00,0x80,0xC0,...  // 上半部分（前 8 行）
    0x00,0x01,0x03,0x07,...  // 下半部分（后 8 行）
};

// OLED_Data.h 中声明
extern const uint8_t Return[];

// 代码中使用
OLED_ShowImage(0, 0, 16, 16, Return);
```

和中文显示的区别：中文走字库查找（Index → Data），图标直接用数组名引用。
