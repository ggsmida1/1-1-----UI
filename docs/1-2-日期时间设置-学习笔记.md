# 1-2 日期时间设置 — 学习笔记

## 学习目标

本节重点是学习“多级页面”和“修改 RTC 时间”的实现方式。它不是单纯 UI 页面，而是把按键事件、RTC 全局时间数组、字段边界处理组合起来。

对应代码：

- `APP/src/app_settings.c`
- `APP/src/app_set_time.c`
- `SYSTEM/src/MyRTC.c`
- `HARDWARE/src/Key.c`

## 单片机知识点

### 1. RTC 时间数组

项目用全局数组保存当前时间：

```c
uint16_t MyRTC_Time[] = {2023, 1, 1, 23, 59, 55};
```

含义：

```text
0: 年
1: 月
2: 日
3: 时
4: 分
5: 秒
```

设置页面修改数组后，调用 `MyRTC_SetTime()` 写回 RTC 计数器。

### 2. 页面层级

设置功能分两层：

```text
App_Settings()
└── App_SetTime_Run()
    ├── SetYear()
    ├── SetMonth()
    ├── SetDay()
    ├── SetHour()
    ├── SetMin()
    └── SetSec()
```

每一层都是阻塞式循环，按确认键进入下一层或返回上一层。

### 3. 边界处理

时间字段不能无限加减：

- 月：1 到 12
- 日：1 到 31，当前没有按月份精确判断
- 时：0 到 23
- 分、秒：0 到 59

项目使用简单环绕逻辑，例如分钟从 59 加 1 回到 0。

## 代码解析

### `App_Settings()`

这是设置入口页，只提供两个选项：

- 返回。
- 日期时间设置。

选择日期时间设置后调用：

```c
App_SetTime_Run();
```

### `App_SetTime_Run()`

该函数维护 `set_time_flag`，表示当前高亮字段：

```text
1: 返回
2: 年
3: 月
4: 日
5: 时
6: 分
7: 秒
```

确认后再进入对应字段的设置函数。

### `Change_RTC_Time()`

该函数只做两件事：

1. 修改 `MyRTC_Time[i]`。
2. 调用 `MyRTC_SetTime()` 写回硬件 RTC。

这样 UI 显示、全局时间数组、RTC 硬件计数器保持同步。

## 注意点

- 目前日期只限制 1 到 31，没有区分大小月和闰年。
- 每次加减都会写 RTC，逻辑简单，但频繁写入时需要注意响应速度。
- `set_time_flag` 是页面状态变量，离开页面后仍保留上次位置。
- `App_SetTime_Run()` 是应用入口，`SetYear()` 等函数只是内部字段编辑函数。
