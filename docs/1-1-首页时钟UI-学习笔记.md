# 1-1 首页时钟 UI — 学习笔记

## 学习目标

本节目标不是“把时间显示出来”这么简单，而是建立这个项目最基础的三件事：

- OLED 如何用显存缓冲刷新界面。
- RTC 如何提供年月日时分秒。
- 主循环如何用按键在首页、菜单、设置页之间跳转。

对应代码：

- `USER/main.c`
- `APP/src/app_home.c`
- `APP/src/app_launcher.c`
- `HARDWARE/src/OLED.c`
- `SYSTEM/src/MyRTC.c`

## 单片机知识点

### 1. OLED 显存缓冲

0.96 寸 OLED 是 128x64 像素。项目里不是每画一个像素就立刻发给屏幕，而是先写入 `OLED_DisplayBuf`，再通过 `OLED_Update()` 一次性刷新。

这种方式的好处：

- UI 可以先在内存中合成，最后统一显示。
- 反色、高亮、图片叠加都可以在缓冲区里完成。
- 减少边画边刷带来的闪烁。

### 2. RTC 实时时钟

STM32F103 的 RTC 本质上是一个秒计数器。项目里通过 `mktime()` 和 `localtime()` 在“年月日时分秒”和“秒计数”之间转换。

关键点：

- LSE 32.768KHz 晶振适合 RTC。
- 预分频 `32768 - 1` 后得到 1Hz。
- `BKP_DR1` 用作是否已初始化 RTC 的标记。
- 项目按东八区处理时间：读写时加减 `8 * 60 * 60`。

### 3. 阻塞式页面循环

项目当前没有 RTOS，也没有全局状态机。每个页面基本是一个 `while (1)` 循环：

```c
clkflag1 = App_Home();
if (clkflag1 == 1) { App_Menu(); }
else if (clkflag1 == 2) { App_Settings(); }
```

首页返回 `1` 表示进入菜单，返回 `2` 表示进入设置。页面之间靠函数返回切换。

## 代码解析

### `App_Init()`

`APP/src/app_launcher.c` 集中初始化应用依赖的硬件模块：

```c
MyRTC_Init();
Key_Init();
LED_Init();
MPU6050_Init();
AD_Init();
```

这样 `main.c` 不需要知道每个应用具体依赖哪些驱动。

### `App_Home()`

`APP/src/app_home.c` 负责首页：

- `Key1` / `Key2` 在“菜单”和“设置”之间移动高亮。
- `Key3` 确认当前选项并返回给 `main()`。
- `Key3` 长按返回按键值 `4`，执行软关机逻辑。

### `Show_Clock_UI()`

每次刷新首页时：

1. 调用 `Show_Battery()` 显示电量。
2. 调用 `MyRTC_ReadTime()` 从 RTC 读时间。
3. 使用 `OLED_Printf()` 显示日期和时间。
4. 使用 `OLED_ReverseArea()` 做选中高亮。

## 注意点

- 首页是阻塞式循环，只有返回后才会进入菜单或设置页。
- `OLED_Update()` 是真正刷新屏幕的动作。
- RTC 第一次初始化会写入默认时间，后续靠备份寄存器判断是否需要重新配置。
- 长按关机目前不是硬件断电，只是进入停机式死循环。
