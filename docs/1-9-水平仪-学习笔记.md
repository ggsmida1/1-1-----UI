## 二、实现

```c
void Show_Gradienter_UI(void)
{
    MPU6050_Calculation();                                // 1. 读传感器
    OLED_DrawCircle(64, 32, 30, OLED_UNFILLED);           // 2. 外框
    OLED_DrawCircle(64 - Roll, 32 + Pitch, 4, OLED_FILLED); // 3. 气泡
}
```

**就这么三行。**

## 三、气泡移动原理

### 3.1 坐标映射

```
气泡 X = 64 - Roll
气泡 Y = 32 + Pitch

板子向右倾斜（Roll > 0）：
  气泡 X 减小 → 气泡向左移
  （看起来像气泡朝"上坡"方向漂）

板子向前倾斜（Pitch > 0）：
  气泡 Y 增大 → 气泡向下移
```

### 3.2 可视化

```
        外框大圆（R=30，圆心 64,32）

     ┌─────────────────────────┐
     │           ●             │  ← 气泡（R=4，实心）
     │     （64-Roll,           │
     │      32+Pitch）          │
     │                         │
     │         ○ 圆心           │
     │        (64,32)           │
     └─────────────────────────┘
```

## 四、为什么不用新文件

水平仪本质是"把已有数据（Roll/Pitch）用绘图函数画出来"。所有依赖都已就绪：

| 依赖 | 来源 | 状态 |
|:---|:---|:---:|
| MPU6050 初始化 | `Menu_Init()` → `MPU6050_Init()` | ✅ 1-6 已有 |
| Roll/Pitch 数据 | `menu.c` 全局变量 | ✅ 1-6 已有 |
| `MPU6050_Calculation()` | `menu.c` 函数 | ✅ 1-6 已有 |
| `OLED_DrawCircle()` | OLED 驱动 | ✅ 1-1 已有 |

**能复用的全部复用，新增代码不到 20 行。**

## 五、1-9 新知识点

| 知识点 | 在哪用到的 |
|:---|:---|
| **实用化 MPU6050** | Roll/Pitch 直接驱动 UI，不是纯显示数字 |
| **坐标映射** | `64 - Roll` 取反让气泡向倾斜方向移动 |
| **空心 vs 实心圆** | `OLED_UNFILLED`（外框）vs `OLED_FILLED`（气泡） |
| **代码复用** | 零新文件，全用已有基础设施 |
