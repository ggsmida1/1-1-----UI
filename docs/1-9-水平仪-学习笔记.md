# 1-9 水平仪 — 学习笔记

## 学习目标

本节重点是学习如何复用 MPU6050 姿态解算结果，把 Roll/Pitch 映射成 OLED 上的气泡位置。

对应代码：

- `APP/src/app_gradienter.c`
- `HARDWARE/src/MPU6050.c`
- `HARDWARE/src/OLED.c`

## 单片机知识点

### 1. 传感器数据复用

水平仪没有重新读取一套传感器数据，而是复用：

```c
MPU6050_Calculation();
extern float Roll, Pitch, Yaw;
```

这说明一个底层驱动可以服务多个应用：

- 姿态显示页显示 Roll/Pitch/Yaw 数值。
- 水平仪用 Roll/Pitch 控制气泡位置。

### 2. 坐标映射

OLED 圆心固定在 `(64, 32)`。气泡位置由姿态角偏移：

```c
OLED_DrawCircle(64 - (int16_t)Roll, 32 + (int16_t)Pitch, 4, OLED_FILLED);
```

含义：

- Roll 改变 x 坐标。
- Pitch 改变 y 坐标。
- 强制转换为 `int16_t`，因为屏幕坐标是整数。

### 3. 简单可视化

本节没有复杂算法，重点是把传感器数据变成可视化反馈。嵌入式 UI 常见模式就是：

```text
采样 -> 计算 -> 映射 -> 绘制 -> 刷新
```

## 代码解析

### `App_Gradienter_Run()`

页面循环中：

1. 检测 `Key3` 是否返回。
2. 清屏。
3. 调用 `Show_Gradienter_UI()`。
4. 刷新 OLED。

### `Show_Gradienter_UI()`

该函数做三件事：

```c
MPU6050_Calculation();
OLED_DrawCircle(64, 32, 30, OLED_UNFILLED);
OLED_DrawCircle(64 - (int16_t)Roll, 32 + (int16_t)Pitch, 4, OLED_FILLED);
```

外圈是水平仪边界，小圆是气泡。

## 注意点

- 当前没有限制气泡越界，倾角过大时气泡可能画到外圈外。
- Roll/Pitch 没有做平滑显示，抖动会直接体现在气泡上。
- 水平仪复用 MPU6050 算法，因此 MPU6050 初始化必须在 `App_Init()` 中完成。
