# 单片机基础知识补全笔记

## 阅读目标

这篇不是某个功能的记录，而是给整个 STM32 手表项目补底层概念。建议在看各章节功能笔记前先读一遍。

## 1. 单片机是什么

单片机可以理解为一颗集成了 CPU、Flash、SRAM 和外设控制器的小型计算机。

在本项目中：

- Flash：存放程序和常量资源。
- SRAM：存放变量、栈、OLED 显存缓冲。
- GPIO：控制 LED、按键、模拟 I2C。
- Timer：产生 1ms 中断。
- ADC：读取电池电压。
- RTC：保持时间。
- I2C：和 OLED、MPU6050 通信，这里主要用软件模拟。

## 2. 编译到烧录流程

项目使用 Keil 工程：

```text
C 源码 / 汇编启动文件
-> ARM Compiler 6.22 编译
-> 链接生成 Template.axf
-> FromELF 生成 Template.hex
-> ST-Link 烧录到 Flash
```

主要文件：

- `USER/Template.uvprojx`：Keil 工程文件。
- `OBJ/Template.axf`：链接后的调试文件。
- `OBJ/Template.hex`：最终烧录文件。

## 3. GPIO 基础

GPIO 是通用输入输出引脚。

项目中的例子：

- `PC13`：输出，控制 LED。
- `PB1/PA6/PA3`：输入，读取按键。
- `PB8/PB9/PB10/PB11`：输出/开漏，模拟 I2C。
- `PA0`：模拟输入，用作 ADC。

常见模式：

- 推挽输出：适合直接输出高低电平。
- 开漏输出：适合 I2C 这种总线。
- 上拉输入：按键松开时保持高电平。
- 模拟输入：ADC 采样使用。

## 4. 时钟系统

单片机所有外设都依赖时钟。外设没开时钟，寄存器配置通常不会生效。

项目中常见写法：

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);
```

含义是开启 GPIOC 外设时钟。

本项目关键时钟：

- 系统主频：常见配置为 72MHz。
- TIM2：用于 1ms 中断。
- RTC：使用 LSE 32.768KHz。
- ADC：需要配置 ADC 时钟分频。

## 5. 中断和 NVIC

中断是硬件或外设打断主程序，让 CPU 先执行一段紧急代码。

本项目核心中断：

```c
void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        App_Tick_1ms();
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}
```

中断里只做短任务：

- 按键扫描。
- 秒表计时。
- 游戏状态推进。

不建议在中断里做：

- OLED 大量刷新。
- 长延时。
- 复杂计算。

## 6. I2C 总线

I2C 用两根线通信：

- SCL：时钟线。
- SDA：数据线。

本项目有两套软件 I2C：

- OLED：PB8/PB9。
- MPU6050：PB10/PB11。

软件 I2C 的本质是用 GPIO 模拟 Start、Stop、发送字节、读取 ACK 等时序。

开漏输出适合 I2C，因为总线上多个设备可以共同拉低 SDA/SCL，释放后由上拉电阻拉高。

## 7. ADC

ADC 把模拟电压转换成数字值。STM32F103 ADC 为 12 位：

```text
0V -> 0
Vref -> 4095
```

项目用 `PA0` 读取电池电压估算电量。由于实际电池需要分压、校准和曲线映射，所以当前百分比只是近似参考。

## 8. RTC

RTC 是实时时钟。它适合做日期时间显示。

项目中：

- LSE 32.768KHz 提供 RTC 时钟。
- RTC 计数器按秒递增。
- `MyRTC_Time[]` 保存年月日时分秒。
- `BKP_DR1` 判断 RTC 是否已初始化。

## 9. 裸机程序结构

本项目没有 RTOS，采用裸机阻塞式页面模型：

```text
main()
└── while (1)
    ├── App_Home()
    ├── App_Menu()
    └── App_Settings()
```

优点：

- 简单。
- 容易理解。
- 适合小项目。

缺点：

- 某个页面阻塞时，其他页面不会运行。
- 动画和按键响应需要自己控制。
- 功能继续变多后，需要考虑状态机或任务调度。

## 10. 当前项目分层

```text
APP       应用和页面逻辑
HARDWARE  硬件驱动
RES       UI 资源
SYSTEM    系统基础模块
USER      主入口和 Keil 工程
```

阅读代码时可以按这个顺序：

1. 从 `USER/main.c` 看主流程。
2. 从 `APP/src/app_menu.c` 看应用入口。
3. 从具体 `APP/src/app_xxx.c` 看页面逻辑。
4. 从 `HARDWARE/src` 看硬件实现。
5. 从 `RES/src/ui_resources.c` 看图片和字模。

## 11. 常用术语速查

| 术语 | 含义 |
|:---|:---|
| GPIO | 通用输入输出引脚 |
| RCC | 复位和时钟控制模块 |
| NVIC | Cortex-M 中断控制器 |
| ISR | 中断服务函数 |
| ADC | 模数转换器 |
| RTC | 实时时钟 |
| I2C | 双线串行通信总线 |
| OLED 显存 | 内存中的屏幕缓冲区 |
| tick | 固定周期节拍 |
| blocking | 阻塞式执行，函数不返回前后续代码不会运行 |
