## 二、硬件适配

### 2.1 参考教程 vs 实际板子

| | 参考教程 | 我们的板子 |
|:---|:---|:---|
| LED 方式 | 外接 LED 模块到 PA1/PA2 排针 | 板载 LED 在 PC13 |
| 数量 | 2 个独立 LED | 1 个 |
| 默认状态 | 由代码控制 | 上电常亮（PC13 默认低） |

**解决：** 把 `LED.c` 中所有 GPIO 操作从 `GPIOA, Pin_1/2` 改为 `GPIOC, Pin_13`。

### 2.2 为什么 PC13 默认亮

STM32F103 的 PC13 上电默认是 RTC 功能引脚，处于低电平。而板载 LED 是**低电平有效**（低 = 亮，高 = 灭）。所以上电就亮。

初始化后配置为推挽输出 + 写高电平，LED 就灭了。

## 三、GPIO 控制 LED 回顾

### 3.1 基本操作

```c
// 开灯：ResetBits = 输出低电平 = LED亮（低电平有效）
GPIO_ResetBits(GPIOC, GPIO_Pin_13);

// 关灯：SetBits = 输出高电平 = LED灭
GPIO_SetBits(GPIOC, GPIO_Pin_13);
```

### 3.2 为什么用低电平点亮

```
VCC ─── LED ─── 电阻 ─── GPIO 引脚
                           │
                     低电平=亮 (电流从VCC流到GPIO)
                     高电平=灭 (没有电压差)
```

接 VCC 的 LED 用低电平驱动（Sink Current），比高电平驱动（Source Current）更稳。大多数 STM32 板子的 LED 都是这样接的。

### 3.3 初始化要点

```c
void LED_Init(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);  // 先开时钟！
    // 配置为推挽输出、50MHz
    // 初始状态：关（高电平）
    GPIO_SetBits(GPIOC, GPIO_Pin_13);
}
```

## 四、手电筒交互逻辑

和秒表一样，OFF/ON 是**即时生效**的：

```c
case 2:  // OFF — 移上去就关灯
    Show_LED_UI();
    LED_OFF();       // ← 即时执行
    ...

case 3:  // ON — 移上去就开灯
    Show_LED_UI();
    LED_ON();        // ← 即时执行
    ...
```

这样用户切换 ON/OFF 只需要按一次方向键，不需要确认。

## 五、1-5 新知识点

| 知识点 | 在哪用到的 |
|:---|:---|
| **低电平有效** | LED 亮 = GPIO 拉低（ResetBits） |
| **硬件适配** | 参考用 PA1/PA2，我们改成 PC13 |
| **板载 vs 外接** | PC13 是板载，PA1/PA2 是排针引出 |
| **即时生效按钮** | OFF/ON 不需要确认，移上去就执行 |
