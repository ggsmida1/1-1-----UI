# 1-10 ADC 电池检测与长按关机 — 学习笔记

## 学习目标

本节重点是学习 ADC 单次转换、简单电量估算、长按按键检测，以及软关机逻辑。

对应代码：

- `HARDWARE/src/AD.c`
- `HARDWARE/src/Key.c`
- `APP/src/app_home.c`
- `APP/src/app_tick.c`
- `HARDWARE/inc/board_config.h`

## 单片机知识点

### 1. ADC 模数转换

ADC 把模拟电压转换成数字值。STM32F103 的 ADC 是 12 位，所以结果范围是：

```text
0 -> 4095
```

项目中 PA0 对应 `ADC_Channel_0`。

### 2. ADC 初始化流程

`AD_Init()` 主要步骤：

1. 开启 ADC 和 GPIO 时钟。
2. 配置 PA0 为模拟输入。
3. 设置 ADC 时钟分频。
4. 配置规则通道。
5. 使能 ADC。
6. 执行校准。

### 3. 单次转换

`AD_GetValue()` 每调用一次就启动一次软件转换：

```c
ADC_SoftwareStartConvCmd(ADCx, ENABLE);
while (ADC_GetFlagStatus(ADCx, ADC_FLAG_EOC) == RESET);
return ADC_GetConversionValue(ADCx);
```

这种方式简单，但调用方会阻塞等待转换完成。

### 4. 长按检测

`Key3_Tick()` 每 1ms 调用一次：

```c
if (GPIO_ReadInputDataBit(KEY3_PORT, KEY3_PIN) == 0)
    press_time++;
else
    press_time = 0;
```

当 `press_time > 1000`，认为 Key3 长按超过 1 秒。

## 代码解析

### `Show_Battery()`

首页电池显示流程：

1. 连续采样多次 ADC。
2. 求平均值。
3. 换算成近似电量百分比。
4. 显示数字和电池图标。

当前百分比公式：

```c
Battery_Capacity = (ADValue - 3276) * 100 / 819;
```

它假设某个 ADC 范围对应 0% 到 100%，属于经验估算。

### `App_Tick_1ms()`

长按检测依赖调用顺序：

```c
Key3_Tick();
Key_Tick();
```

先累计按下时间，再由 `Key_Tick()` 采样按键状态，才能区分短按和长按。

### 软关机逻辑

首页检测到按键值 `4` 后执行：

```c
GPIO_ResetBits(PWR_CTRL1_PORT, PWR_CTRL1_PIN);
GPIO_SetBits(PWR_CTRL2_PORT, PWR_CTRL2_PIN);
while (1);
```

如果硬件没有真正电源控制电路，这里表现为停机/冻屏，而不是完全断电。

## 注意点

- ADC 电池检测需要结合实际分压电路校准，否则百分比只能参考。
- 多次采样取平均能减小抖动，但也会增加首页刷新耗时。
- 长按检测和按键消抖都依赖 1ms tick。
- 如果以后加入低功耗模式，软关机逻辑应改成进入 sleep/stop 或控制电源 MOSFET。
