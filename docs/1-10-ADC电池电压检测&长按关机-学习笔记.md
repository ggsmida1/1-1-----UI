## 二、ADC 模数转换

### 2.1 什么是 ADC

```
模拟电压（电池）  →  ADC  →  数字值（0~4095）
   3.3V                       4095
   0V                         0
```

STM32F103 的 ADC 是 **12 位**，精度 = 3.3V / 4096 ≈ 0.8mV。

### 2.2 ADC 配置流程

```c
// 1. 开时钟
RCC_APB2PeriphClockCmd(RCC_APB2Periph_ADC1, ENABLE);
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

// 2. 配置时钟分频（12MHz）
RCC_ADCCLKConfig(RCC_PCLK2_Div6);  // 72M/6 = 12MHz

// 3. GPIO 设为模拟输入模式
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AIN;  // PA0
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;

// 4. 配置规则组通道
ADC_RegularChannelConfig(ADC1, ADC_Channel_0, 1, ADC_SampleTime_55Cycles5);

// 5. ADC 初始化：独立模式、右对齐、软件触发、单次转换
ADC_Init(ADC1, &结构体);

// 6. 使能 + 校准
ADC_Cmd(ADC1, ENABLE);
// 固定校准流程...
```

### 2.3 读 ADC 值

```c
uint16_t AD_GetValue(void)
{
    ADC_SoftwareStartConvCmd(ADC1, ENABLE);  // 软件触发一次
    while (ADC_GetFlagStatus(ADC1, ADC_FLAG_EOC) == RESET);  // 等完成
    return ADC_GetConversionValue(ADC1);     // 返回 0~4095
}
```

## 三、电量计算

### 3.1 电压换算

```
ADValue（0~4095）→ 电压 → 电量百分比

VBAT = ADValue / 4095 × 3.3                      // 实际电压
Battery_Capacity = (ADValue - 3276) × 100 / 819   // 映射到 0~100%

3276 ≈ 3.3V 对应 ADC 值的 80%（锂电池满电 ~4.2V 经过分压后）
819  ≈ 3.3V 对应 ADC 值的 20%
```

**实际项目中参数根据电池分压电路调节，这里的是参考值。**

### 3.2 多次采样取平均

```c
int sum = 0;
for (int i = 0; i < 3000; i++)
{
    sum += AD_GetValue();
}
ADValue = sum / 3000;  // 3000 次采样的平均值
```

ADC 单次采样有噪声，取 3000 次平均消除抖动。AD_GetValue 很快（单次约几微秒），3000 次总耗时约几十毫秒，不影响 UI 刷新。

### 3.3 电池图标绘制

```c
// 满电：完整电池图标
// 高电（10%~99%）：图标 + 用 ClearArea 擦掉右边表示剩余
// 低电（<10%）：图标 + 擦掉右边 + 擦掉百分比数字
```

用 `OLED_ClearArea` 擦除像素来表示电量消耗，而不是准备多张不同电量的图。

## 四、长按检测

### 4.1 原理

```c
int press_time;

void Key3_Tick(void)  // 每 1ms 调用
{
    if (PA3 == 0)      // 按键按下
        press_time++;   // 计数器累加
    else
        press_time = 0; // 松手清零
}

// 在 Key_GetState 中判断：
if (PA3 按下 && press_time > 1000)  // 按了超过 1000ms
    return 4;  // 长按
else if (PA3 按下)
    return 3;  // 短按
```

| 条件 | 返回值 | 触发功能 |
|:---|:---:|:---|
| PA3 按下 < 1s 然后松开 | 3 | 确认/退出 |
| PA3 按下 > 1s 然后松开 | 4 | 关机 |

**关键细节：** `press_time` 只在 Key3 按下期间累积，松手立即清零。短按和长按用同一个按键，靠持续时间区分。

### 4.2 为什么要在 Key_Tick 之前调用 Key3_Tick

```c
// ISR 中的顺序
Key3_Tick();   // 先更新 press_time
Key_Tick();    // 再读按键状态（内部调 Key_GetState）
```

`Key_Tick` 的 `Key_GetState` 需要用到 `press_time`，所以必须先调 `Key3_Tick` 更新它。

## 五、关机逻辑

```c
else if (KeyNum == 4)  // 首页收到长按
{
    GPIO_ResetBits(GPIOB, GPIO_Pin_13);  // PB13 低
    GPIO_SetBits(GPIOB, GPIO_Pin_12);    // PB12 高
    while (1);                            // 死循环，停在这里
}
```

PB12 和 PB13 在参考硬件的 PCB 上连接了电源 MOSFET，拉低/拉高可以切断电池供电。在通用的最小系统板上没有这个电路，所以关机 = 单片机冻屏。
