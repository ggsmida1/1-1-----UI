## 二、动画结构

### 2.1 两阶段循环

```
睁眼阶段（3 帧）  →  闭眼阶段（3 帧）  →  停顿 500ms  →  重复
        ↓                    ↓
  眉毛：Y=10→12        眉毛：Y=12→10
  眼睛：6×6→6×4        眼睛：6×4→6×6
  （越变越小）          （越变越大）
```

### 2.2 睁眼帧

```c
for (uint8_t i = 0; i < 3; i++)
{
    OLED_Clear();
    OLED_ShowImage(30, 10 + i, 16, 16, Eyebrow[0]);   // 眉毛下移
    OLED_ShowImage(82, 10 + i, 16, 16, Eyebrow[1]);
    OLED_DrawEllipse(40, 32, 6, 6 - i, OLED_FILLED);  // 眼睛缩小
    OLED_DrawEllipse(88, 32, 6, 6 - i, OLED_FILLED);
    OLED_ShowImage(54, 40, 20, 20, Mouth);
    OLED_Update();
    Delay_ms(100);   // 每帧 100ms
}
```

| 帧 | i | 眉毛 Y | 眼睛大小 |
|:---:|:---:|:---:|:---:|
| 1 | 0 | 10 | 6×6（正常） |
| 2 | 1 | 11 | 6×5 |
| 3 | 2 | 12 | 6×4（最细） |

### 2.3 闭眼帧

方向相反——眉毛上移，眼睛从细变回正常：

| 帧 | i | 眉毛 Y | 眼睛大小 |
|:---:|:---:|:---:|:---:|
| 1 | 0 | 12 | 6×4（最细） |
| 2 | 1 | 11 | 6×5 |
| 3 | 2 | 10 | 6×6（正常） |

**一共 6 帧 × 100ms + 停顿 500ms = 每轮约 1.1 秒。**

## 三、OLED 绘图函数

### 3.1 DrawEllipse（画椭圆）

```c
OLED_DrawEllipse(40, 32, 6, 6 - i, OLED_FILLED);
//              X   Y   A   B      是否填充
//             圆心 圆心 横轴 纵轴
```

- A = 横轴半径，B = 纵轴半径
- `B = 6 - i`：纵轴从 6 渐变到 4（眼睛慢慢眯起来）
- `OLED_FILLED`：实心椭圆

### 3.2 ShowImage vs 绘图函数

| 方式 | 用在哪 | 原因 |
|:---|:---|:---|
| `OLED_ShowImage` | 眉毛、嘴巴 | 不规则形状，取模更精确 |
| `OLED_DrawEllipse` | 眼睛 | 纯椭圆，绘图函数比取模简单 |

**原则：规则图形用绘图函数，不规则图形用取模。**

## 四、帧动画参数设计

```
每帧延迟 = 100ms → 每秒 10 帧
眨眼周期 = 6 帧 ≈ 0.6 秒
停顿时间 = 500ms
总周期 ≈ 1.1 秒

人眼自然眨眼速度 ≈ 100~400ms
适当放慢让动画更明显、更可爱
```

## 五、1-8 新知识点

| 知识点 | 在哪用到的 |
|:---|:---|
| **帧动画循环** | `for (i = 0; i < 3; i++)` 两阶段动画 |
| **椭圆绘图** | `OLED_DrawEllipse` 画真实的眼睛 |
| **渐变参数** | `6 - i` 和 `4 + i` 让眼睛/眉毛逐帧变化 |
| **图像 vs 绘图取舍** | 眉毛取模（复杂形状），眼睛绘图（规则椭圆） |
| **动画时序** | `Delay_ms(100)` 控制帧率，`Delay_ms(500)` 控制停顿 |
