# 1-8 动态表情包 — 学习笔记

## 学习目标

本节重点是学习 OLED 上的简单帧动画，以及图片资源和基础图形函数如何组合成动态效果。

对应代码：

- `APP/src/app_emoji.c`
- `RES/src/ui_resources.c`
- `HARDWARE/src/OLED.c`

## 单片机知识点

### 1. 帧动画

动态表情不是视频，而是多帧画面连续刷新：

```text
睁眼帧 1 -> 睁眼帧 2 -> 睁眼帧 3 -> 闭眼帧 1 -> 闭眼帧 2 -> 闭眼帧 3
```

每一帧之间用 `Delay_ms(100)` 控制速度。

### 2. 图片资源和绘图函数

表情由两类内容组成：

- 图片资源：眉毛、嘴巴。
- 绘图函数：椭圆眼睛。

图片资源来自 `RES/src/ui_resources.c`，绘制函数来自 `OLED.c`。

### 3. 阻塞式动画

`App_Emoji_Run()` 在 while 循环中不断调用 `Show_Emoji_UI()`。动画过程中会阻塞一段时间，但当前项目没有 RTOS，这种做法简单直接。

## 代码解析

### `Show_Emoji_UI()`

该函数分两段：

1. 睁眼动画：眼睛椭圆逐渐变扁。
2. 闭眼动画：眼睛椭圆逐渐恢复。

每一帧都执行：

```c
OLED_Clear();
OLED_ShowImage(...);
OLED_DrawEllipse(...);
OLED_Update();
Delay_ms(100);
```

### `App_Emoji_Run()`

页面循环中检测 `Key3`：

- 按下确认键返回菜单。
- 否则继续播放表情动画。

## 注意点

- 当前按键检测只在一轮动画之间进行，动画播放中按键响应会有延迟。
- 图片和图形混合绘制时，顺序会影响遮挡效果。
- 如果动画帧数增加，建议把帧参数整理成数组，避免重复代码。
