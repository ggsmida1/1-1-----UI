# 1-4 秒表 — 学习笔记

## 学习目标

本节重点是学习“中断节拍驱动计时”。秒表显示页面在主循环中运行，但计时本身由 TIM2 的 1ms tick 推进。

对应代码：

- `APP/src/app_stopwatch.c`
- `APP/src/app_tick.c`
- `SYSTEM/src/Timer.c`
- `USER/main.c`

## 单片机知识点

### 1. TIM2 1ms 中断

`SYSTEM/src/Timer.c` 配置 TIM2 定时中断。当前工程让 TIM2 每 1ms 进入一次 `TIM2_IRQHandler()`。

中断入口在 `USER/main.c`：

```c
void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        App_Tick_1ms();
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}
```

### 2. 1ms 到 1s 的转换

秒表 tick 函数里用计数器累计 1000 次：

```c
Count++;
if (Count >= 1000)
{
    Count = 0;
    sec++;
}
```

因为 1 次 tick 是 1ms，所以 1000 次就是 1s。

### 3. ISR 中只做短任务

中断里不直接画 OLED，也不处理复杂页面逻辑，只推进状态：

- 按键扫描。
- 秒表计时。
- 小恐龙游戏节拍。

这样可以减少中断占用时间。

## 代码解析

### `App_Tick_1ms()`

集中维护 1ms 周期任务：

```c
Key3_Tick();
Key_Tick();
App_Stopwatch_Tick();
App_Dino_Tick();
```

这样 `main.c` 不需要直接依赖每个具体应用。

### `App_Stopwatch_Tick()`

该函数只负责时间增加，不负责 UI：

- `start_timing_flag == 1` 时计时。
- 秒满 60 进位到分钟。
- 分钟满 60 进位到小时。
- 小时超过 99 回到 0。

### `App_Stopwatch_Run()`

这是秒表页面入口。它负责：

- 显示返回、开始、停止、清除。
- 用高亮表示当前选项。
- 根据选项修改 `start_timing_flag` 或清零时间。

## 注意点

- 计时状态和显示页面分离：tick 负责时间，页面负责交互。
- `start_timing_flag` 是秒表内部状态。
- 当前秒表精度受 TIM2 配置、中断延迟和阻塞代码影响。
- OLED 刷新不应放进中断。

## 复盘问题

1. 为什么秒表计时适合放在 1ms tick 中？
2. `App_Stopwatch_Tick()` 为什么不直接刷新 OLED？
3. 如果要支持毫秒显示，需要改哪些变量和 UI？
4. `App_Tick_1ms()` 作为集中调度入口有什么好处？
