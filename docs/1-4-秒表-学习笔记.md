## 二、ISR 驱动计时

### 2.1 为什么放中断里

秒表需要**精确计时**，每秒要准。如果放主循环，按键处理、屏幕绘制都会拖慢它。

```
TIM2 中断（每 1ms）              主循环
─────────────────              ─────────
Key_Tick()                      StopWatch()  ← 只负责 UI
StopWatch_Tick()                ↑ 只看 hour/min/sec 变量
  ├── Count 累加                    │ 中断负责更新数值
  ├── Count ≥ 1000 → 1 秒到了      │ 主循环负责显示数值
  ├── start_timing_flag == 1?     
  └── sec++, 进位处理
```

**核心原则：中断管数值，主循环管显示。两者通过全局变量 `hour/min/sec` 通信。**

### 2.2 为什么是 1000？

```c
void StopWatch_Tick(void)
{
    static uint16_t Count;
    Count++;                    // 每次 +1
    if (Count >= 1000)          // 1000 次 = 1000ms = 1 秒
    {
        Count = 0;              // 重置计数器
        if (start_timing_flag == 1)
        {
            sec++;              // 秒 +1
            // 进位链...
        }
    }
}
```

TIM2 每 1ms 中断一次 → `Count` 每 ms +1 → 1000 次 = 恰好 1 秒。

### 2.3 进位链

```c
sec++;
if (sec >= 60)          // 60秒 = 1分
{
    sec = 0;
    min++;
    if (min >= 60)      // 60分 = 1时
    {
        min = 0;
        hour++;
        if (hour > 99)  // 最大 99 时
            hour = 0;
    }
}
```

和 1-2 的日期边界处理一样，秒 → 分 → 时的级联进位。

## 三、即时生效 vs 确认按钮

### 3.1 两种交互模式

| 模式 | 怎么触发 | 用在 |
|:---|:---|:---|
| **确认触发** | 移到选项 → 按 Key3 确认 → 执行 | 返回（退出页面） |
| **即时生效** | 移到选项 → 立即执行 | 开始、停止、清除 |

### 3.2 实现方式

```c
switch (stopwatch_flag)
{
    case 1:  // 返回（确认触发）
        Show_StopWatch_UI();
        OLED_ReverseArea(0, 0, 16, 16);
        OLED_Update();
        break;              // 只是高亮，不做任何操作

    case 2:  // 开始（即时生效）
        Show_StopWatch_UI();
        start_timing_flag = 1;  // ← 移上来就设置！
        OLED_ReverseArea(8, 44, 32, 16);
        OLED_Update();
        break;

    case 3:  // 停止（即时生效）
        Show_StopWatch_UI();
        start_timing_flag = 0;  // ← 移上来就清零！
        OLED_ReverseArea(48, 44, 32, 16);
        OLED_Update();
        break;

    case 4:  // 清除（即时生效）
        Show_StopWatch_UI();
        start_timing_flag = 0;
        hour = min = sec = 0;   // ← 移上来就清零！
        OLED_ReverseArea(88, 44, 32, 16);
        OLED_Update();
        break;
}
```

**即时生效的秘密：** 不需要等待 `stopwatch_flag_temp`，直接在 switch-case 的渲染分支里把操作做了。每次移动到该选项时，操作就被执行一次。

### 3.3 为什么秒表用即时生效

秒表的核心操作（开始/停止）需要**快**。如果按两下（选择 + 确认），100 米冲刺都跑完了。移上去就触发 = 一键操作。

## 四、过渡动画 MenuToFunction()

```c
void MenuToFunction(void)
{
    for (uint8_t i = 0; i <= 6; i++)
    {
        OLED_Clear();
        OLED_ShowImage(x_pre, 16 + 8 * i, 32, 32, Menu_Graph[...]);
        OLED_Update();
    }
}
```

选中菜单项确认后，图标从 `y=16` 往下滑到 `y=16+8*6=64`（屏幕底部消失），创造"进入功能"的视觉效果。7 帧 × 循环执行一次 = 一瞬间的动画。

## 五、1-3 遗留修复

### Set_Selection 调整

```c
// 1-3 版本（有 bug）
void Set_Selection(...)
{
    if (move_flag == 1) {
        ...
        Menu_Animation();  // 只在 move_flag==1 时调用
    }
}

// 1-4 修复版本
void Set_Selection(...)
{
    if (move_flag == 1) {
        ...
    }
    Menu_Animation();      // 每次都调用，确保动画持续运行
}
```

修复后动画每一帧都会更新，不会有"卡住"的问题。

## 六、1-4 新知识点

| **ISR 驱动定时** | `StopWatch_Tick()` 在中断中，每秒精确 +1 |

| **确认触发按钮** | 返回通过 `stopwatch_flag_temp` 确认后执行 |
| **过渡动画** | `MenuToFunction()` 图标下坠效果 |
| **进位链** | sec→min→hour 三级级联 |
