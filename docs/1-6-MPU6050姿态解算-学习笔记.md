## 二、MPU6050 是什么

### 2.1 六轴传感器

```
MPU6050 = 三轴加速度计 + 三轴陀螺仪 + 温度传感器

加速度计：测 XYZ 三个方向的加速度
  - 静止时：Z 轴 ≈ 1g（重力），X/Y ≈ 0
  - 倾斜时：重力分量出现在不同轴上 → 可算倾角

陀螺仪：测 XYZ 三个轴的旋转角速度
  - 转动时输出角速度（°/s）
  - 角速度 × 时间 = 旋转角度 → 可算姿态
```

### 2.2 接线

```
MPU6050 (GY-521)        STM32
─────────────────      ──────
    VCC      ───────→ 3.3V
    GND      ───────→ GND
    SCL      ───────→ PB10
    SDA      ───────→ PB11
    其余引脚          不接（悬空）
```

I2C 地址：`0x68`（写=0xD0，读=0xD1）。AD0 悬空/GND 时用 `0x68`，接 VCC 时用 `0x69`。

## 三、软件 I2C（MyI2C）

### 3.1 为什么又写一套 I2C

OLED 已经用了一套软件 I2C（PB8/PB9），MPU6050 另开一套（PB10/PB11）。

| | OLED I2C | MPU6050 I2C |
|:---|:---|:---|
| SCL | PB8 | PB10 |
| SDA | PB9 | PB11 |
| 实现文件 | OLED.c | MyI2C.c |
| 延时 | 无 | Delay_us(10) |
| 从机地址 | 0x78 | 0xD0 |

**原理完全一样**，就是复制粘贴改管脚。I2C 起始/停止/发送/接收/应答的逻辑一模一样。

### 3.2 新增能力：接收字节

OLED 只需要**发送**数据给屏幕。MPU6050 需要**读取**传感器数据，所以 MyI2C 比 OLED 的 I2C 多了：

```c
// 从 MPU6050 接收一个字节
uint8_t MyI2C_ReceiveByte(void)
{
    uint8_t Byte = 0x00;
    MyI2C_W_SDA(1);                          // 释放 SDA，让从机控制
    for (i = 0; i < 8; i++)
    {
        MyI2C_W_SCL(1);                      // 主机发时钟脉冲
        if (MyI2C_R_SDA()) { Byte |= (0x80 >> i); }  // 读 SDA
        MyI2C_W_SCL(0);
    }
    return Byte;
}
```

## 四、MPU6050 驱动

### 4.1 I2C 读写寄存器

传感器内部有一组寄存器，通过 I2C 读写：

```c
// 写寄存器：I2C 起始 → 发从机地址(写) → 发寄存器地址 → 发数据 → 停止
void MPU6050_WriteReg(uint8_t RegAddress, uint8_t Data);

// 读寄存器：I2C 起始 → 发从机地址(写) → 发寄存器地址
//           → 重复起始 → 发从机地址(读) → 接收数据 → 停止
uint8_t MPU6050_ReadReg(uint8_t RegAddress);
```

### 4.2 初始化配置

```c
MPU6050_WriteReg(MPU6050_PWR_MGMT_1, 0x01);   // 唤醒，选陀螺仪 X 轴为时钟
MPU6050_WriteReg(MPU6050_PWR_MGMT_2, 0x00);   // 所有轴不休眠
MPU6050_WriteReg(MPU6050_SMPLRT_DIV, 0x04);   // 采样率分频
MPU6050_WriteReg(MPU6050_CONFIG, 0x06);        // 数字低通滤波
MPU6050_WriteReg(MPU6050_GYRO_CONFIG, 0x18);   // 陀螺仪 ±2000°/s
MPU6050_WriteReg(MPU6050_ACCEL_CONFIG, 0x18);  // 加速度计 ±16g
```

### 4.3 读取六轴数据

```c
int16_t ax, ay, az;  // 加速度计 XYZ
int16_t gx, gy, gz;  // 陀螺仪 XYZ

MPU6050_GetData(&ax, &ay, &az, &gx, &gy, &gz);
```

每个轴的值是 **16 位有符号整数**，高 8 位 + 低 8 位拼接：

```c
DataH = MPU6050_ReadReg(REG_H);
DataL = MPU6050_ReadReg(REG_L);
*Value = (DataH << 8) | DataL;  // 高8位 | 低8位 = 16位
```

## 五、互补滤波 — 核心算法

### 5.1 为什么需要滤波

| 传感器 | 优点 | 缺点 |
|:---|:---|:---|
| 加速度计 | 长期稳定，不漂移 | 受振动影响大，动起来就不准 |
| 陀螺仪 | 瞬时响应快，不受振动影响 | 积分会累积误差，会漂移 |

**互补滤波 = 加速度计的长期精度 + 陀螺仪的瞬时响应。**

### 5.2 算法步骤

```c
float a = 0.9;  // 互补滤波系数（陀螺仪权重 90%，加速度计 10%）

// 步骤1：陀螺仪积分 → 动态角度
roll_g  = Roll  + gx * 0.005;   // 角速度 × 时间 = 角度变化
pitch_g = Pitch + gy * 0.005;
yaw_g   = Yaw   + gz * 0.005;

// 步骤2：加速度计反算 → 静态角度
pitch_a = atan2(-ax, az) * 180 / π;  // 反正切算倾角
roll_a  = atan2( ay, az) * 180 / π;

// 步骤3：加权融合
Roll  = a * roll_g  + (1-a) * roll_a;   // 90% 陀螺仪 + 10% 加速度计
Pitch = a * pitch_g + (1-a) * pitch_a;
Yaw   = a * yaw_g;                       // Yaw 没有加速度计参考，只能积分
```

### 5.3 系数 `a` 的含义

```
a = 0.9  →  高速滤波器（90%信陀螺仪）
1-a = 0.1 → 低速补偿（10%信加速度计）

a 越大 → 响应越快，但漂移越明显
a 越小 → 越稳定，但响应越迟钝
```

## 六、欧拉角（Roll / Pitch / Yaw）

```
Roll  (横滚)  —  绕 X 轴旋转，左右倾斜
Pitch (俯仰)  —  绕 Y 轴旋转，前后倾斜
Yaw   (偏航)  —  绕 Z 轴旋转，水平转向
```

```
       Z (上)
       │
       │   Roll = ±180°
       │  / 
       │ /___ Y (前)
       │
       X (右)
       
  Pitch = ±90°（超过 90° 会万向节死锁）
  Yaw   = ±180°（无加速度计参考，会漂移）
```

## 七、踩坑记录

### Delay_Init 未调用导致黑屏

`Delay_us()` 依赖 SysTick 定时器，如果 `Delay_Init()` 没调，`fac_us = 0`，导致 `SysTick->LOAD = 0`，计数器溢出耗时约 2 秒，MPU6050 初始化直接卡死。**在 main() 最开始加 `Delay_Init()` 解决。**
