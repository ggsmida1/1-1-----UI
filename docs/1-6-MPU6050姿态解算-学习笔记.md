# 1-6 MPU6050 姿态解算 — 学习笔记

## 学习目标

本节重点是学习软件 I2C、MPU6050 寄存器读写、六轴数据读取和互补滤波。它是项目里第一个明显涉及“外部传感器 + 算法”的模块。

对应代码：

- `HARDWARE/src/MyI2C.c`
- `HARDWARE/src/MPU6050.c`
- `APP/src/app_mpu6050_ui.c`
- `HARDWARE/inc/MPU6050_Reg.h`

## 单片机知识点

### 1. MPU6050 是什么

MPU6050 是六轴传感器：

- 三轴加速度计：AccX、AccY、AccZ。
- 三轴陀螺仪：GyroX、GyroY、GyroZ。

项目用它估算：

- Roll：绕 X 轴倾斜。
- Pitch：绕 Y 轴倾斜。
- Yaw：绕 Z 轴旋转。

### 2. 软件 I2C

项目没有使用 STM32 硬件 I2C 外设，而是用 GPIO 模拟 I2C 时序。

MPU6050 连接：

```text
PB10 -> SCL
PB11 -> SDA
```

软件 I2C 的核心动作：

- Start。
- Stop。
- SendByte。
- ReceiveByte。
- SendAck / ReceiveAck。

### 3. 寄存器读写

MPU6050 的配置和数据都通过寄存器访问。写寄存器流程：

```text
Start -> 设备地址 -> 寄存器地址 -> 数据 -> Stop
```

读寄存器流程：

```text
Start -> 设备地址(写) -> 寄存器地址
Start -> 设备地址(读) -> 读取数据 -> Stop
```

## 代码解析

### `MPU6050_Init()`

初始化主要配置：

- 解除睡眠。
- 设置采样率。
- 设置低通滤波。
- 设置陀螺仪量程。
- 设置加速度计量程。

### `MPU6050_GetData()`

依次读取 6 个轴的高低字节，并拼成 `int16_t`：

```c
*AccX = (DataH << 8) | DataL;
```

传感器数据是有符号数，所以使用 `int16_t`。

### `MPU6050_Calculation()`

姿态解算分三步：

1. 陀螺仪积分，得到短时间内变化趋势。
2. 加速度计用 `atan2()` 反算 Roll/Pitch。
3. 用互补滤波融合两者：

```c
Roll  = a * roll_g  + (1 - a) * roll_a;
Pitch = a * pitch_g + (1 - a) * pitch_a;
Yaw   = a * yaw_g;
```

## 注意点

- Yaw 没有磁力计或其他绝对参考，会随时间漂移。
- 当前 `Delay_ms(5)` 固定采样周期，属于简单阻塞式实现。
- 软件 I2C 对时序比较敏感，`Delay_us()` 必须先初始化。
- 量程配置会影响原始值换算精度，当前代码没有完整单位换算。
